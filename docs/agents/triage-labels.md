# Triage 标签

Matt Pocock Skills 使用五种标准 triage role。本文件将这些 role 映射到仓库实际使用的 GitHub label。

| Role | GitHub label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，Agent 可以直接处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或判断 |
| `wontfix` | `wontfix` | 不会处理 |

Skill 提到 triage role 时，使用本表对应的 GitHub label，并复用这些标签，不创建同义标签。
